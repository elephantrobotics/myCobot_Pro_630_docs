# Modbus
## 1 操作步骤

### 1.1 进入程序编辑界面
运行RoboFlow后，选择空白程序（after run RoboFlow,select empty program），具体如下图所示：<br>
![](../resourse/6-ApplicationBaseRoboFlow/6.6/6.6.1.1.png)<br>

### 1.2 进入配置界面
选择工具--》配置，具体如下图所示：<br>
![](../resourse/6-ApplicationBaseRoboFlow/6.6/6.6.1.2.png)<br>

### 1.3 添加RTU设备
选择modbus-->RTU-->添加RTU设备--》选择端口号（485USB的）--》将从设备ID设为1（此处从设备Id是唯一的，如果添加多个RTU设备，每个设备的从设备ID不能设为一致），具体如下图所示：<br>
![](../resourse/6-ApplicationBaseRoboFlow/6.6/6.6.1.3.png)<br>

### 1.4 添加信号
点击添加信号--》选择类型（也就是modbus功能码协议）--》设置地址--》名称（设置自己容易识别的），具体如下图所示:<br>
功能码协议：<br>
1、05-Digital Output：对单个线圈进行写操作<br>
2、01-Digital Input：读线圈寄存器，可读单个或多个<br>
3、06-Register Output：写单个保持寄存器，把设置的二进制值写入单一寄存器，只能写一个<br>
4、04-Register Input：读输入寄存器，读输入寄存器，可读单个或者多个<br>
![](../resourse/6-ApplicationBaseRoboFlow/6.6/6.6.1.4.png)<br>

### 1.5 设置界面配置
点击基础功能--》设置--》选择协议--》设置值（digital的值为0/1，regesiter没有限制）--》勾选Set Modbus，具体所下图所示：<br> 
![](../resourse/6-ApplicationBaseRoboFlow/6.6/6.6.1.5.png)<br>

### 1.6 等待界面配置
点击基础功能--》等待--》勾选Wait Modbus-->选择协议--》设置值（运行时，如果值不为设置的值，将会一直等待） ，具体所下图所示：<br> 
![](../resourse/6-ApplicationBaseRoboFlow/6.6/6.6.1.6.png)<br>

### 1.7 设置弹窗
点击高级功能--》弹窗--》弹窗内容（内容可自己设定）--》控制处选择弹窗时停止程序<br>
此处功能为：点击运行后，如果等待处设置的值一致，将会出现ok！的弹窗，如果不一致，不会出现弹窗，会一直循环，具体所下图所示：<br> 
![](../resourse/6-ApplicationBaseRoboFlow/6.6/6.6.1.7.png)<br>

### 1.8 运行
9、点击弹窗下面的高级功能--》点击无限循环，具体所下图所示：<br> 
![](../resourse/6-ApplicationBaseRoboFlow/6.6/6.6.1.8.png)<br>
