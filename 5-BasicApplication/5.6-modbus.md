# Modbus
## 1 Operation steps

### 1.1 Enter the program editing interface
After running RoboFlow, select an empty program, as shown in the figure below:
![](../resourse/6-ApplicationBaseRoboFlow/6.6/6.6.1.1.png)<br>

### 1.2 Enter the configuration interface
Select "Tools" --> "Configuration", as shown in the figure below: <br>
![](../resourse/6-ApplicationBaseRoboFlow/6.6/6.6.1.2.png)<br>

### 1.3 Add RTU device
Select modbus-->RTU-->Add RTU device-->Select port number (485USB)-->Set the slave device ID to 1 (the slave device ID here is unique. If multiple RTU devices are added, the slave device ID of each device cannot be set to the same value). The specific steps are shown in the figure below:
![](../resourse/6-ApplicationBaseRoboFlow/6.6/6.6.1.3.png)<br>

### 1.4 Adding signals
Click "Add Signal" --> Select Type (i.e., Modbus Function Code Protocol) --> Set Address --> Name (set a name that is easy for you to recognize), as shown in the figure below:
Function code protocol: <br>
1. 05-Digital Output: Performing write operations on a single coil
2. 01-Digital Input: Read coil register, capable of reading single or multiple entries
3. 06-Register Output: Write a single hold register, write the set binary value into a single register, and only one value can be written
4. 04-Register Input: Read input register. Can read single or multiple input registers
![](../resourse/6-ApplicationBaseRoboFlow/6.6/6.6.1.4.png)<br>

### 1.5 Setting interface configuration
Click on "Basic Functions" --> "Settings" --> "Select Protocol" --> "Set Value" (the value for "digital" is 0/1, and there is no limit for "register") --> check "Set Modbus", as shown in the figure below: <br>
![](../resourse/6-ApplicationBaseRoboFlow/6.6/6.6.1.5.png)<br>

### 1.6 Waiting for interface configuration
Click on "Basic Functions" --> "Wait" --> tick "Wait Modbus" --> select "Protocol" --> set the value (During runtime, if the value is not the set value, it will keep waiting). The specific steps are shown in the following figure: <br>
![](../resourse/6-ApplicationBaseRoboFlow/6.6/6.6.1.6.png)<br>

### 1.7 Set up pop-up windows
Click on "Advanced Features" --> Pop-up window --> Pop-up content (content can be customized) --> Select "Stop program when pop-up appears" in the control area
The function here is as follows: After clicking "Run", if the values set in the waiting area are consistent, a pop-up window will appear with the message "ok!". If they are not consistent, no pop-up window will appear and the process will continue to loop. The specifics are shown in the following figure: <br>
![](../resourse/6-ApplicationBaseRoboFlow/6.6/6.6.1.7.png)<br>

### 1.8 Operation
9. Click on "Advanced Features" below the pop-up window --> click on "Infinite Loop", as shown in the figure below: <br>
