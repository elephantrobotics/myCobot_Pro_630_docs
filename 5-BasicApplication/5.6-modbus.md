# Modbus
## 1 Operation steps

### 1.1 Enter the program editing interface
After running RoboFlow, select an empty program, as shown in the figure below:

<img src="/resources/2-serialproduct/myCobot%20Pro%20600/English/6.6.1.1.jpg" width="50%" >
### 1.2 Enter the configuration interface
Select "Tools" --> "Configuration", as shown in the figure below:

<img src="/resources/2-serialproduct/myCobot%20Pro%20600/English/6.6.1.2.jpg" width="50%" >

### 1.3 Add RTU device
Select modbus --> RTU --> Add RTU Device --> Select Port Number (485USB) --> Set the Slave ID to 1 (the Slave ID here is unique. If multiple RTU devices are added, the Slave ID of each device cannot be set to the same value). The specific steps are shown in the following figure:

<img src="/resources/2-serialproduct/myCobot%20Pro%20600/English/6.6.1.3.jpg" width="50%" >

### 1.4 Add Signal
Click "Add Signal" --> Select Type (i.e., Modbus Function Code Protocol) --> Set Address --> Name (set a name that is easy for you to recognize), as shown in the figure below:
Function code protocol: <br>
1. 05-Digital Output: Write operation on a single coil
2. 01-Digital Input: Read coil register, capable of reading single or multiple entries
3. 06-Register Output: Write a single hold register, write the set binary value into a single register, and only one value can be written
4. 04-Register Input: Read input register. This can be done for a single or multiple inputs

<img src="/resources/2-serialproduct/myCobot%20Pro%20600/English/6.6.1.4.jpg" width="50%" >

### 1.5 Setting interface configuration
Click on "Basic Functions" --> "Settings" --> "Select Protocol" --> "Set Values" (the value for "digital" is 0/1, and there is no limit for "register") --> check "Set Modbus", as shown in the figure below:

<img src="/resources/2-serialproduct/myCobot%20Pro%20600/English/6.6.1.5.jpg" width="50%" >

### 1.6 Waiting for interface configuration
Click on "Basic Functions" --> "Wait" --> check "Wait Modbus" --> select "Protocol" --> set the value (During operation, if the value is not the set value, it will keep waiting). The specific steps are shown in the following figure:

<img src="/resources/2-serialproduct/myCobot%20Pro%20600/English/6.6.1.6.jpg" width="50%" >

### 1.7 Set up pop-up windows
Click on "Advanced Features" --> Pop-up Window --> Pop-up Content (content can be customized) --> Select "Stop Program" in the control area when the pop-up appears
The function here is: after clicking "Run", if the values set in the waiting area are consistent, a pop-up window will appear saying "ok!". If they are not consistent, no pop-up window will appear and the process will keep looping, as shown in the specific figure below:

<img src="/resources/2-serialproduct/myCobot%20Pro%20600/English/6.6.1.7.jpg" width="50%" >
