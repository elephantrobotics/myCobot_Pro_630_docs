# Joint control and coordinate control
In RoboFlow, joint and coordinate control is available on the **QuickMove** page. To run RoboFlow and access the program editing interface, select **Tools--QuickMove** (for instructions on how to enter the program editing interface, please refer to **5.1 Simple Usage of RoboFlow**). The control methods for the robot arm movement are divided into **continuous movement** and **step movement**. For continuous movement, the robot arm will only stop moving after the button is released. For step movement, set the increment, and the robot arm will stop when it reaches the designated point
## 1 Joint Control
Joint Control refers to joint control, where Joint1-6 correspond to joints 1-6 respectively (myPalletizer 260 has four joints, with Joint1-4 corresponding to joints 1-4 respectively)
Function description: <br>
1.1 At the "Speed" setting, choose between "Continue Motion" and "Discrete Motion". If it's "Discrete Motion", you need to set the increment value;<br>1.2 At the "Joint Control" section, each joint has buttons for increasing and decreasing the angle. To decrease the angle, press the button on the minus side, and to increase the angle, press the button on the plus side. For "Continue Motion", the motion will continue until the button is released (or until it reaches the limit). For "Discrete Motion", the motion will stop when it reaches the desired point (for example, if Joint 1 is currently at angle 30 and the increment value is 50, and you press the button on the minus side, the robotic arm will stop moving at -20). ## 2 Coordinate Control
Note: Before using coordinate control, you need to press the home button first (for 280, you need to press the home button; for 320, you just need to click the home button once) to make the robotic arm reach a certain pose. After reaching the pose, click the home button again, and it will prompt "The robotic arm has reached the required point."
![](../resourse/6-ApplicationBaseRoboFlow/6.3/6.3.2.png)<br>

Coordinates Control refers to coordinate control
Function description: <br>
2.1 Select "Continue Motion" or "Discrete Motion" for "speed". If it is "Discrete Motion", an increment value needs to be set
2.2 Coordinates Control: Each coordinate axis has a plus and minus button. To decrease, press the button on the minus side, and to increase, press the button on the plus side. For continuous motion, pressing the button will continue until it is released (or until it reaches a limit). For step-by-step motion, it will stop when it reaches the desired point (for example, if the current coordinate of the X-axis is 30 and the increment value is 50, pressing the plus button will cause the robotic arm to move to 80 and then stop).
